# 🌟 Premium Portfolio Website

A modern, responsive, and professional portfolio website designed to showcase my skills, projects, achievements, and career journey. Built using HTML, CSS, Bootstrap, and JavaScript, this portfolio provides an engaging user experience across desktop, tablet, and mobile devices.

## 📖 About the Project

This portfolio serves as a personal branding platform where visitors can learn about my background, technical skills, projects, achievements, and contact information. The website features a clean user interface, smooth navigation, and responsive design to ensure accessibility on all devices.

## ✨ Features

* Responsive and mobile-friendly design
* Professional landing page with introduction
* About Me section
* Skills showcase
* Project gallery with descriptions
* Achievements section with interactive cards
* Resume download functionality
* Contact form
* Social media integration
* Smooth scrolling navigation
* Modern Bootstrap components and styling

## 🛠️ Tech Stack

* HTML5
* CSS3
* Bootstrap 5
* JavaScript

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/sarayuchikakolla/Portfolio.git
```

### Navigate to the Project Directory

```bash
cd Portfolio
```

### Run the Project

Open `index.html` directly in your browser

**OR**

Use VS Code Live Server:

1. Open the project in VS Code
2. Right-click on `index.html`
3. Select **Open with Live Server**
